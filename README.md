# ❤️ CardioLab
### Human Performance & Cardiovascular Analytics

## Project Overview

CardioLab is a Python-based sports science analytics dashboard designed to explore cardiovascular measurements and heart rate recovery patterns.

The project combines data analysis, statistical methods, and interactive visualizations to investigate relationships between cardiovascular measurements.

## Features

- Interactive athlete dashboard
- Individual athlete profiles
- Athlete comparison tools
- Heart rate recovery visualizations
- Interactive data exploration
- Correlation and regression analysis
- CSV data upload

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## Research Questions

- How does heart rate change following exercise?
- How do cardiovascular measurements vary between simulated athletes?
- What relationships exist between selected cardiovascular variables?
- How can statistical analysis help explore human performance data?

## Data Disclaimer

The current dataset contains 100 simulated athlete records. It is intended for educational and software development purposes and does not represent actual clinical measurements or real athletes.
